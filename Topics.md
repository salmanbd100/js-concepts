# ✅ Senior JavaScript Engineer - Important Topics Checklist

## ✅ 1. Core JavaScript (ES6+ and Fundamentals)

- Scoping: `var`, `let`, `const`, block scope vs function scope
- Hoisting
- Closures
- `this` keyword and how it behaves in different contexts
- Prototype chain & Inheritance
- Execution context & call stack
- Lexical Environment
- Event Loop, Callbacks, Microtasks, Macrotasks
- Promises and `async/await`
- Debounce and Throttle
- Currying, Composition, Partial application
- Deep vs Shallow Copy
- Value vs Reference types
- Type Coercion & Equality (`==` vs `===`)
- Strict Mode
- Garbage Collection basics

## ✅ 2. Functions

- First-class functions
- Higher-order functions
- Arrow functions vs regular functions
- Function binding: `call`, `apply`, `bind`
- IIFE (Immediately Invoked Function Expressions)
- Pure functions, side-effects, and referential transparency

## ✅ 3. Objects & Arrays

- Object methods: `Object.assign`, `Object.keys`, `Object.entries`, `Object.freeze`
- Array methods: `map`, `filter`, `reduce`, `find`, `some`, `every`, `flat`, `splice`, `slice`, `sort`
- Spread & Rest operators (`...`)
- Destructuring
- Optional chaining (`?.`), Nullish coalescing (`??`)
- Set, Map, WeakMap, WeakSet

## ✅ 4. Asynchronous JavaScript

- Callbacks
- Promise chaining
- Async/Await
- `Promise.all`, `Promise.race`, `Promise.allSettled`
- Error handling with `try/catch` in async functions
- Real-world API call patterns (exponential backoff, retry, timeout)

## ✅ 5. Browser APIs & DOM

- DOM Traversal and Manipulation
- Event bubbling, capturing, delegation
- `addEventListener` options (`once`, `capture`, `passive`)
- `localStorage`, `sessionStorage`, cookies
- `fetch`, `AbortController`, and handling HTTP requests
- History API (`pushState`, `replaceState`)
- Clipboard API, Notification API, Intersection Observer

## ✅ 6. Error Handling & Debugging

- `try/catch`, `finally`
- Error types: `ReferenceError`, `TypeError`, `SyntaxError`
- Custom error handling
- Logging techniques and debugging tools (DevTools, breakpoints)
- Memory leaks and performance profiling

## ✅ 7. Modular JavaScript

- ES Modules: `import/export`
- CommonJS
- Module bundlers (Webpack, Vite, Parcel - just basic awareness)
- Tree shaking and code splitting

## ✅ 8. Testing (must-know for senior roles)

- Unit testing with Jest or Mocha
- Test-Driven Development (TDD)
- Mocking and spying (`jest.fn`, `sinon`)
- E2E testing tools (like Cypress, Playwright)
- Code coverage analysis

## ✅ 9. Security & Performance

- XSS, CSRF basics
- Secure HTTP headers
- Avoiding memory leaks
- Lazy loading, async/defer scripts
- Debounce/throttle, virtualization
- Performance profiling tools (Lighthouse, Chrome DevTools)

## ✅ 10. Design Patterns & Architecture

- Singleton, Factory, Module, Observer
- Pub/Sub
- MVC, MVVM
- State management patterns
- Clean code principles
- SOLID principles in JavaScript context

## ✅ 11. Data Structures & Algorithms in JS

- Arrays, Linked Lists, Trees, Graphs
- Recursion
- Sorting and Searching algorithms
- Big O Notation
- Common problems: anagrams, palindrome, throttling, deep clone

## ✅ 12. TypeScript (very important for modern teams)

- Type inference and annotations
- Interfaces and types
- Enums, generics
- Utility types (`Partial`, `Pick`, `Omit`, etc.)
